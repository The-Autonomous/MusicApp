Connect your existing YouTube account

MusicApp is waiting for your Chrome or Edge profile. Your normal browser stays open.

  1. Sign in to YouTube in this browser profile if needed.
  2. Return to this tab. Open the MusicApp YouTube connection extension from the browser toolbar and click Connect.

First-time extension setup

Open edge://extensions or chrome://extensions, turn on Developer mode, choose Load unpacked, and select MusicApp's browser_connector folder beside its executable. Then return to this connection tab.

The extension reads only YouTube cookies, only when you click Connect. It hands them to MusicApp on this computer, which verifies the account and remembers the session using Windows encryption. It has no background worker and does not modify your browser cookies. This connection expires after five minutes.

You can also use MusicApp's normal Sign in button without installing this extension. That uses a separate remembered Chrome/Edge profile.
